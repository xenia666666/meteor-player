# Meteor IPTV Player

APK releases for Android phones, tablets and Android TV.

[Stiahnuť najnovší meteor.apk / Download latest APK](https://github.com/xenia666666/meteor-player/releases/latest/download/meteor.apk)

## Inštalácia

- Android 8.0 alebo novší.
- Pri aktualizácii pôvodnú aplikáciu neodinštaluj; otvor nové APK a potvrď aktualizáciu v Androide.
- Používanie vyžaduje aktiváciu zariadenia a vlastný oprávnený zdroj obsahu.
- Aplikácia neposkytuje vlastné TV stanice ani predplatné.

## Releases

This repository distributes the released APK. Each release lists its version and SHA-256 checksum. The stable latest-download link above points to `meteor.apk` in the release marked Latest.
